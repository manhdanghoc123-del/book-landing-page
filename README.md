# Dự Án Static Book Landing Page

Trang web tĩnh giới thiệu sách được xây dựng bằng HTML5, CSS3 và Bootstrap 5 với thiết kế tối ưu Responsive trên đa dạng màn hình.

## Các Phần Cốt Lõi
- **Header & Navbar**: Menu điều hướng linh hoạt với hiệu ứng cuộn mượt (Smooth Scroll).
- **Book Overview**: Tổng quan về sách và nút hành động chính.
- **Author**: Thông tin giới thiệu tác giả.
- **Features**: Những tính năng / giá trị nổi bật của sách.
- **Prices**: Bảng giá dịch vụ / sản phẩm dạng thẻ so sánh.
- **Download**: Form nhận bản đọc thử qua Email.
- **Reader's Say**: Đánh giá và cảm nhận thực tế từ độc giả.
- **Footer**: Thông tin bản quyền.

## Công Nghệ Sử Dụng
- HTML5 / CSS3
- Bootstrap 5.3
- Bootstrap Icons

## Hướng Dẫn Chạy Dự Án
1. Tải dự án về máy hoặc `git clone`.
2. Mở file `index.html` trên trình duyệt bất kỳ.
